# Музыка — промпты Suno для фракций LO Galactic Strategy

Промпты на **английском** (Suno лучше понимает теги жанра). Лимит: **до 1000 символов** на промпт.

## Как использовать

1. Откройте `.md` нужной фракции.
2. Скопируйте блок **«Промпт Suno»** целиком в поле Lyrics/Style (или Custom Mode → Style of Music).
3. Для инструментала в Suno добавьте в настройках **Instrumental**.
4. При необходимости укажите длительность 2–4 мин для темы фракции, 30–60 с для UI-стинга.
