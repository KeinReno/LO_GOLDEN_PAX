### T3.9. Caravan — убрать ложную аффорданс (или сделать настоящий приказ)

**Диагноз:** жест «ресурс → система / кнопка Караван» выглядит как рабочий приказ, но
`ViewerPage.caravanHint` только открывает систему и пишет тост «перевозку оформите приказом на карте».
Отдельного intent в `content/core/intents.json` нет. Ложная аффорданс подрывает доверие ко всему
жестовому языку (тот же класс проблемы, что мёртвый код — только на уровне обещания UI).

Сделай **одно** из двух (предпочтительный порядок):

1. **Настоящий приказ (предпочтительно):** в мире уже есть `world.caravans` + `advanceCaravans` в
   `processTurn.mjs` (доставка с `reason: "caravan_delivery"`). Добавь intent-def + applier, который
   создаёт запись каравана (списание со склада → ETA/доставка на систему) и подключи Склад/map DropZone
   к `submitPlayerIntent`, а не к `caravanHint`. Стоимость ОД — по аналогии с соседними logistics-интентами.
2. **Честный отказ:** если полный intent в этом проходе неподъёмен — убери/переименуй жест так, чтобы он
   не выглядел завершённым действием: нет кнопки «Караван» как peer к «Продать»; drop на систему не
   имитирует успех; тост только из явно вторичного «Как перевезти?» help, не из основного drop-path.

Не оставляй `caravanHint` как основной onDrop/onClick путь. Зафиксируй выбор (1 или 2) в summary.

2. Проверь статус `B7-hud-paths-strip` (`../agents-pathways/`) — если он трогал `ViewerPage.tsx`, синхронизируй

   уже приземлиться** до этой декомпозиции — иначе слайсы зафиксируют старую IA дока; см.
   `../agents-roadmap/README.md` Фаза III–IV.
3. Вынеси состояние **одной** секции панели за раз в отдельный Zustand-слайс (`src/state/` — по образцу уже

   `useEffect`/условий с другими панелями — определи по факту чтения, не гадай заранее).
