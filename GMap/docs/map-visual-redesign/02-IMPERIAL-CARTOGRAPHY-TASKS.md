## Идея направления

Иллюминированный звёздный атлас, а не дебаг-оверлей поверх пустоты. Продолжает то, что уже есть в бренде: золото `#c9a227`/`#e8c547` и засечный шрифт Cinzel с экрана входа (`ViewerPage.tsx`), плюс уже существующая «двойная золотая окантовка» в `drawTerritoryBorders` (`drawMapIcons.ts:1192-1220`) — эта задача не изобретает окантовку с нуля, а обобщает то, что уже написано.

Статика важнее движения: минимум анимации (в отличие от направления Б), акцент на гравировку/чёткость линии.

**Обязательно:** все цвета фракции — через `resolveFactionThemeColors(faction)` (см. `01-SHARED-FOUNDATION-TASKS.md`, Задача 2). Никаких новых хардкод-палитр по фракциям. Единственные фиксированные (не-фракционные) цвета в этой теме: `BRASS = 0xc9a227`, `BRASS_SOFT = 0xe8c547`, тёмный рельс `0x06080c` — это цвет бренда/чертежа, не фракции, используется как внешняя окантовка одинаково для всех.

## Задача 1 — Заливка территории (без стопки колец)

В `imperialTheme.ts`, `drawTerritory(...)`:
- Взять полигональный fill-путь, который уже есть в `drawTerritoryGlow` (`drawMapIcons.ts` ~1124-1132: `poly.length >= 3` → `g.fill({color, alpha: rich ? 0.17 : 0.22})`) — это ОДИН слой заливки на весь блоб, уже правильный по духу.
- **НЕ переносить** цикл `rings = [...]` (~1153-1167) с 4-5 концентрическими эллипсами на каждое ядро — это и есть источник «каши», от которого уходим. Ядра (`blob.cores`)/мосты (`blob.bridges`) в этой теме заливкой не покрываются отдельно — только общий контур блоба.
- Цвет: `factionColors.get(faction.id)?.fill ?? 0x888888`.
- Альфа: 0.16–0.20 (чуть плотнее текущих 0.012 из `drawSectors`, но без слоёв — единственный слой должен быть заметен сам по себе).

**Acceptance:** плотная группа из 5+ систем одной фракции — заливка читается как ровный единый тон, без «пятен» разной яркости в местах скопления систем (это и была визуальная проблема оригинала).

## Задача 2 — Граница: обобщить существующий dual-rail

`drawTerritoryBorders` (`drawMapIcons.ts:1206-1219`) уже делает почти то, что нужно этой теме — 4 прохода `strokePoly`:
```ts
strokePoly(7.5, 0x06080c, 0.55);                          // тёмный рельс снаружи
strokePoly(5.2, color, 0.22 + anim.pulse * 0.06);          // цветной рельс, лёгкая пульсация
strokePoly(2.1, color, 0.82 + anim.pulse * 0.1);            // яркая цветная линия
strokePoly(0.9, 0xc9a227, 0.28 + anim.pulse * 0.08);        // тонкая золотая накладка
```
Перенести эту логику в `imperialTheme.drawTerritoryBorder`, `color = factionColors.get(faction.id)?.border`. Можно оставить пульсацию (`anim.pulse`) — это тонкая, не шумная анимация, соответствует духу «гравировки, которая слегка дышит», не противоречит «статика важнее движения» (в отличие от бегущих импульсов направления Б).

Опционально (не обязательно): чуть уменьшить пульсацию (`* 0.04` вместо `* 0.1`) для более спокойного, «неподвижного атласа» ощущения — на усмотрение реализующего, сравнить визуально с оригиналом.

**Acceptance:** граница территории — чёткая двойная рамка (тёмный рельс + цвет фракции + тонкая золотая нить), совпадает по цвету фракции с заливкой из Задачи 1 (тот же `resolveFactionThemeColors(...).border`).

## Задача 3 — Системы: розетка вместо кольца-мишени

Базовая точка — `drawSystemToken` (`drawMapIcons.ts:104-188`, низкоуровневый «имперский жетон», уже неплохо сочетается с направлением) можно переиспользовать как есть или расширить.

Для `imperialTheme.drawSystem` (не-столичные системы):
- Взять `drawSystemToken(g, p.x, p.y, rimColor, selected, anim, {...})` как основу диска.
- Добавить розетку: 4 (обычная система) или 8 (важная/хаб — на усмотрение, можно ограничиться 4 для всех некапитальных) коротких радиальных штрихов + маленькая точка-центр, цвет = `factionColors.get(...).system` (не `.border`, не `.fill` — это отдельный слот именно для маркеров систем).
- **Сохранить** существующую семантику «обитаемая/необитаемая» (кольцо обитаемости, ~строки 541-562 в `drawSystemGlyph`) — это не фракционный, а статусный сигнал (как светофорный красный/зелёный), должен остаться в текущем зелёном `0x5cdb95`, не перекрашивается в золото. Не путать с Задачей про фракционные цвета — эти два слоя ортогональны.
- Убрать «3-слойное свечение» вокруг звезды (~647-660, три вложенных `g.circle` с нарастающей альфой) — заменить на одно умеренное свечение или убрать вовсе, чтобы не создавать тот же эффект колец на уровне отдельной системы, который мы убираем на уровне территории (Задача 1).

**Acceptance:** обычная система — читается как единый жетон с золотой розеткой, без вложенных полупрозрачных окружностей. Скопление систем не создаёт визуального «боке».

## Задача 4 — Столица: розетка покрупнее + один контур

Базовая точка — капитанская ветка `drawSystemGlyph` (`drawMapIcons.ts:587-620`): уже есть 5-конечная звезда (`drawStarPolygon`) и жетон — это хорошо, сохранить.
- Заменить (или дополнить) текущий паттерн на: один контур-кольцо (не стопка) радиусом ~15px, `factionColors.get(...).border`, альфа ~0.75 — вместо потенциальной стопки колец, если она есть на пути выбора/эмфазиса в общем коде.
- Розетка крупнее, чем у рядовых систем (8 лучей вместо 4), тем же золотым/фракционным акцентом на усмотрение — see mockup: розетка была золотой (`0xe8c547`) независимо от фракции, а рим/фон жетона — фракционного цвета (`accent = rim ?? 0xc9a227` уже есть в оригинале, строка 588 — это разумный существующий паттерн, сохранить).
- 5-конечная звезда и белая искра-центр (~строки 598-616 оригинала) — оставить, это уже хорошо работает.

**Acceptance:** столица явно весомее рядовой системы (крупнее, отдельная форма — розетка+звезда, не просто увеличенный жетон), не превращается в мишень из нескольких колец.

## Задача 5 — Подпись фракции: плашка вместо голого текста

`drawFactionLabels` (`drawMapIcons.ts:1284-1367`) уже берёт цвет и шрифт из `resolveFactionNameColor`/`resolveFactionNameFont` — не переизобретать эту часть, она уже фракционно-корректна.

Добавить в `imperialTheme` (или как опциональный параметр в существующую функцию, если её решили не дублировать) — тёмную плашку-подложку под текст с тонкой золотой линией сверху/снизу, по образцу питч-мокапа: `rect` тёмный (`0x0d0e10`, альфа ~0.85) + `stroke` золото альфа ~0.5, текст поверх. Использовать `factionColors.get(...).name` для цвета текста и `.nameFont` для шрифта (уже готово в `FactionThemeColors`, см. `01-SHARED-FOUNDATION-TASKS.md` Задача 2).

**Acceptance:** название державы читается на плашке, а не голым текстом со сплошным чёрным аутлайном/тенью как сейчас — визуально ближе к экрану входа.

## Задача 6 — Плашки иконок-событий

В `src/renderers/mapIconSprites.ts`, `MapIconOverlay` — плашки (`this.plates.circle(...)`, тёмный фон под каждой sprite-иконкой) сейчас однотипные для всех тем. Добавить вариант `"imperial-rim"`: та же тёмная плашка, но с тонким золотым контуром (`stroke: {color: 0xc9a227, width: 0.8, alpha: 0.5}`) вместо/в дополнение к текущей заливке без обводки.

Не менять сами иконки-спрайты (`ICON_PATHS`, `mapIconAssets.ts`) — только плашку-фон, гейтится по `iconPlateStyle` из активной темы (`MapTheme.iconPlateStyle`, см. `01-SHARED-FOUNDATION-TASKS.md` Задача 1). Это единственное место, где эта задача трогает файл, которым НЕ владеет эксклюзивно этот трек — координировать через маленький `switch`/`if` по `iconPlateStyle`, не переписывать всю функцию плашек.

**Acceptance:** значки боя/торговли/квеста получают тонкую золотую обводку плашки в режиме `imperial`, при этом сами силуэты иконок не меняются, режим `classic`/`holo` не затронут.
