# Brief: саунд-дизайнер GMap (рация стола)

Handoff для **другого агента**. Ты не «добавляешь SFX в игру». Ты **саунд-дизайнер** живого имперского штабного стола. Код плеера уже есть. Текущие wav — брак, их надо заменить.

Владелец уже отверг: UI-паки (Kenney и родня), дерево/дуб, нарезку из саундтрека, процедурный шум из `scripts/synthStaffSfx.mjs`. Не предлагай это снова.

Ты — саунд-дизайнер, не геймдев и не «человек, который генерит wav». Игра: GMap / LO Golden Pax. Это живой GM-стол 4X на часы, часто поверх Discord. Интерфейс — голографический штабной стол Империи Белатор (сталь, латунь, стекло, сургуч, сухая рация), не казуальная мобилка и не шутер.

Спроектировать и поставить 5 запоминающихся, чистых, коротких куев одной семьи. Они — сирены штаба, не клики кнопок. После твоей работы игрок должен узнавать стол по звуку за ~200 мс, как по мотиву, но это НЕ музыкальный мотив «Звезда Воли» (колокол + 5 нот) — тот принадлежит OST и запрещён.

- Плеер: GMap/src/audio/staffSfx.ts — playStaffCue(id), mute, громкость, debounce, unlock с жеста.

Проводка кода — готовая. Твоя работа — звук в слотах и соник-байбл. Код трогай только если нужен формат/громкость нормализации, не чтобы «переделать аудиосистему».

ПОЧЕМУ ТЕКУЩЕЕ — БРАК
Локальный синтез (synthStaffSfx.mjs) построил squelch из полосового белого шума. Результат: грязь, шипение, нет тела, нет характера, 4 варианта звучат как один испорченный радиоэфир. ЗАПРЕЩЕНО

СОНИК-БАЙБЛ (это и есть продукт)
Одна семья. Общий ident + разные хвосты.

Ident (должно стать earworm рации, не музыки):
сухой щелчок открытия канала — механический squelch GATE, не шипение. 40–80 мс. Близкий микрофон. Почти без реверба. Можно едва слышный analog click / relay. Шум — только атака <30 мс, потом тишина или чистый тон. Если в файле слышен «телевизор без сигнала» — брак.

Материалы:
- рация штаба: металл, реле, сухой gate
- стол: СТЕКЛО + ЛАТУНЬ (голографический briefing table), не дерево
- печать: латунный штамп + сургуч + плотная бумага на КАМНЕ
Пространство: dry, close-mic, штаб, не зал и не космос-эмбиент.

Пять куев — система, не пять незнакомцев:

1) radio_squelch — 180–350 мс
   Только ident. Самый важный файл: его услышат чаще (RP). Должен быть приятным даже на 40-й раз за сессию. Чисто. Запоминаемо.

2) turn_advance — 450–700 мс
   Ident + ОДИН низкий чистый тон (корпус/щит), без мелодии. «Новый ход», не фанфара. Тон не из OST.

3) contact_alert — 400–650 мс
   Два ident, второй чуть выше или короче, пауза ~150–200 мс. Тревога штаба, не сирена и не выстрел.

4) seal_stamp — 300–550 мс

5) token_drop — 180–400 мс

Громкость: пик согласован между пятёркой (примерно −16 LUFS интегрировано на коротком файле бессмысленно — равняй peak/true peak, чтобы stamp не орал над squelch). Fade-out в ноль, без щелчка в конце (кроме намеренного gate). Mono или узкое stereo. 44.1 или 48 kHz, 16-bit WAV (предпочтительно) или OGG; если OGG — поправь cueUrl в staffSfx.ts.

## Контекст для агента (не дублировать в чат целиком — файл уже здесь)

### Мир
Империя Белатор, живой стол, не экшен. OST (вне скоупа) — гибрид ambient × grimdark, мотив «Звезда Воли». SFX — **другой канал**: рация и материя стола.

### Проводка (GMap)

| id | файл-триггер |
|---|---|
| `radio_squelch` | `src/ui/rpNotify.ts` → `playRpChime` |
| `turn_advance` | `src/ui/TurnStampHud.tsx` |
| `contact_alert` | `src/viewer/hooks/useViewerLivePolls.ts` (новый active engagement) |
| `seal_stamp` | `src/viewer/shared/HoldButton.tsx` |
| `token_drop` | `src/renderers/MapCanvas.tsx` `flashSystem` |

Плеер: `src/audio/staffSfx.ts`. Слоты: `public/audio/sfx/{id}__0N.wav`.

### Что выкинуть из головы
`GMap/scripts/synthStaffSfx.mjs` — генератор брака. Не улучшать; можно оставить как археологию или удалить после замены ассетов, не в начале.

### ElevenLabs
`POST https://api.elevenlabs.io/v1/sound-generation`. С этой машины/региона **заблокирован** (RU в их списке). Скрипт `GMap/scripts/genSfxEleven.mjs` — только с разрешённой сети и ключом в env, не в git.

## How this gets checked

Не «wav на диске». Владелец слушает пятёрку в `/audio/index.html` и за столом. Режектор: шипение, неразличимость, дерево, лазер, мотив OST, новые клики хрома. Принимающий агент сверяет: те же 5 id, плеер не переписан, музыка не тронута, в `SONIC_BIBLE.md` есть семья звука, не список промптов «noise hiss».
