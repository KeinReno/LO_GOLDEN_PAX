# Agent B6 — Гражданские пути: Торговля и Культура

> Ты работаешь над проектом LO_GOLDEN_PAX / GMap. Читай спецификацию целиком, выполняй по порядку.

## Принципы (нерушимые)

См. `../PRINCIPLES.md`.

## Контекст — важно, в сессии было исправление задним числом

- `GMap/docs/ECONOMY_TECH_REDESIGN_SPEC.md` §10 — базовое обоснование двух гражданских путей.
- **Уточнение из более позднего обсуждения (учти это, не более раннюю формулировку в §10 про "показывать
  только тем, кто накопил"):** Гражданские пути **видны всем игрокам с первого хода наравне с материальными**
  — НЕ прячутся. Прятать имеет смысл только то, что физически недостижимо для игрока (Пути Силы у рас без
  доступа — это задача B9, не эта). Торговля/Культура достижимы для любой фракции с первого хода, значит
  видны всегда, просто у большинства будут стоять около нуля первое время — это нормально, ровно как
  материальные пути стоят на нуле, пока не начал добывать.
- 🪙 Путь Торговли — не RoleScore (не добыча), а объём Биржи/договоров.
- 🎭 Путь Культуры — не RoleScore, а доля доминирующей культуры на своих мирах + вера + лояльность.
- `content/core/faiths.json`/`content/core/cultures.json` — сейчас почти пустые заготовки (`faiths.json`
  содержит только `version`/`description`, ни одной реальной записи). Эта задача — первое, что их реально
  наполняет.

## Цепочка задач

### T6.1. `content/core/civic_paths.json`

```json
{
  "civic.trade": {
    "id": "civic.trade",
    "name": "Путь Торговли",
    "icon": "🪙",
    "feedsFrom": ["market_volume", "active_treaties"],
    "unlocks": [
      { "kind": "building", "id": "building.free_port", "name": "Вольный порт" },
      { "kind": "law", "id": "law.open_markets", "name": "Открытые рынки" }
    ]
  },
  "civic.culture": {
    "id": "civic.culture",
    "name": "Путь Культуры",
    "icon": "🎭",
    "feedsFrom": ["dominant_culture_share", "faith_conversion", "avg_loyalty"],
    "unlocks": [
      { "kind": "building", "id": "building.cultural_wonder", "name": "Культурное чудо" },
      { "kind": "law", "id": "law.state_religion", "name": "Государственная религия" }
    ]
  }
}
```

Пороги для `unlocks` — плейсхолдер-числа, не итоговый баланс (как и в B2/B5).

### T6.2. Накопитель Торговли

`civicScore.trade` растёт от: (а) объёма успешных `marketConvert` вызовов фракции за ход (сумма
конвертированного, не число вызовов — иначе фарм спамом мелких сделок), (б) числа активных договоров
(`diplomacy_stances.json` — сосчитай нетривиальные стойки типа `trade`/`alliance`/`research_pact`, не
`neutral`/`war`). Копится накопительно, как RoleScore (не тратится).

### T6.3. Накопитель Культуры

`civicScore.culture` растёт от: (а) доли населения на своих планетах, разделяющего доминирующую культуру
фракции (используй существующий `resolvePlanetCultureId`/composition-механизм из `economyTick.mjs`/
`cultureFaith.mjs`, не изобретай параллельный расчёт), (б) среднего уровня лояльности по фракции
(`loyalty.mjs`), (в) конверсии веры, если есть измеримый показатель в `faiths.json` после наполнения (T6.4).

### T6.4. Наполнить `faiths.json`/`cultures.json` минимально

`faiths.json` сейчас содержит только мета-описание, ни одной веры. Добавь минимум 3-4 реальные записи по
существующему заявленному формату (`taboo properties + effects`, `budgetRange [-2, 2]` — см. текущий файл)
— это открытый контентный пробел, не только техническая подпорка под T6.3. Ориентируйся на уже упомянутые в
`docs/LORE_COSMOLOGY_SPEC.md` темы (например вера, связанная с Псионикой Разума у эланов), но не обязательно
жёстко привязываться к лору — главное, чтобы механизм заработал на реальных данных, а не на пустышке.

### T6.5. `server/civicTick.mjs`

Новый модуль, вызываемый из `processTurn.mjs` рядом с (после) `runEconomyTick()`. Считает `civicScore` для
каждой фракции, пишет в `ledger` (аналогично `eco.roleScore` из B2 — используй тот же паттерн хранения:
`eco.civicScore: Record<"trade"|"culture", number>`).

### T6.6. Разблокировки

При достижении порога — тот же механизм эффекта `unlock_path`/`unlock_property`, что в B5 (переиспользуй,
не дублируй). Постройки/законы из T6.1 создай минимально в `buildings.json`/`taxes.json`-подобном месте для
законов (найди, где в проекте уже хранятся принимаемые фракцией законы/эдикты — если нет отдельного файла,
спроси себя, не создаёт ли это новую top-level таблицу в обход принципа 5, и по возможности встрой как ещё
один `faction_traits.json`-подобный выбираемый трейт).

### T6.7. Миграция и тесты

`eco.civicScore` по умолчанию `{}`. `npm run smoke`, `npm run smoke:tick`.

## DoD

- `civicScore.trade`/`civicScore.culture` реально растут от рыночной активности/культурной доли, видны в API.
- Хотя бы одна разблокировка на каждый путь работает end-to-end (порог → постройка/закон доступны).
- `faiths.json` содержит реальные записи, не только мета.
- `npm run smoke`, `npm run smoke:tick` проходят.
