## Контекст

- `GMap/docs/ECONOMY_TECH_REDESIGN_SPEC.md` — раздел про HUD-схему из конца сессии (10 иконок, единая полоса,
  клик → нужная панель).
- **Правило видимости (важно, не перепутай с более ранней отменённой версией):** 8 материальных + 2
  гражданских = 10 путей, **все видны всегда**, единой компактной полосой (маленькая иконка + тонкая полоска
  прогресса). Пути Силы — **не в этой полосе вообще**, они не про накопление и не про экономику (см. B9,

- Пилот сейчас реально считает данные только для 2 материальных путей (B2) и 2 гражданских (B6) — остальные
  6 материальных иконок в полосе будут стоять "не активны" (0, без порога) до будущих волн. **Это ожидаемо**,
  не баг — покажи их как есть (например приглушённым цветом/иконкой без прогресса), не имитируй фейковые
  данные для непилотных ролей.

## Цепочка задач

### T7.1. Компонент полосы путей

Компактная горизонтальная полоса из 10 иконок (🛡⚡🎯🔰🚀🧠🌱✨ | 🪙🎭), каждая — иконка + тонкая полоска
заполнения (0-100% до следующего порога, если применимо, иначе просто "неактивна"). Располагается рядом со
счётчиком AP в общем HUD (см., где сейчас рендерится AP-индикатор, размещай логически рядом, не в
произвольном месте экрана).

### T7.2. Данные — из реальных API-полей

Читай `roleScore` (B2) и `civicScore` (B6) из существующего economy-эндпоинта/стора, не создавай отдельный
запрос, если данные уже приходят вместе с остальной эко-инфой. Для непилотных ролей (нет данных/нет
threshold в `role_milestones.json`) — показывай иконку в "неактивном" визуальном состоянии, не 0%-заполненный
активный вид (разные вещи: "ещё не начал" vs "эта роль пока не реализована").

### T7.3. Клик → переход к детальной панели

| Иконка | Ведёт на |
|---|---|
| 🛡⚡🎯🔰🚀🌱✨ | Экономика (`src/viewer/economy/`) |
| 🧠 | Наука (`src/viewer/research/`) |
| 🪙 | Биржа (если существует, иначе Экономика) |
| 🎭 | Двор/Дипломатия/Вера (найди существующую панель, вероятно `CourtPanel.tsx`) |

Реализуй как простую навигацию (смена активной вкладки/панели в существующем шелле), не модальное окно.

### T7.4. Подсказка по клику/ховеру — формат база→модификаторы→итог

По клику на конкретную иконку — всплывающая карточка с разбивкой (см. формат из спека §2): текущее значение,
до порога, что откроется. Переиспользуй уже существующий UI-паттерн подсказок в проекте, если есть (проверь
`@floating-ui/react` — уже в зависимостях, используется для похожих поповеров).

### T7.5. Пути Силы — НЕ в этой полосе

Явно не добавляй сюда иконки для Разум/Воля/Хаотетика/Теневодство — они не про накопление, у большинства
фракций их не будет вообще. Если хочешь дать зацепку для фракций с доступом — согласуй отдельный, гораздо
более редкий UI-элемент с задачей B9, не смешивай в эту полосу.

### T7.6. Стили

Plain CSS в `src/styles/app.css`, дизайн-токены проекта (цвета/отступы уже определены — не хардкодь новые
значения, если есть подходящие переменные). Анимация заполнения полоски — `motion` (Framer Motion), уже в
зависимостях.

## DoD

- Полоса из 10 иконок отображается в HUD рядом с AP, с реальными данными по 2+2 пилотным путям.
- Непилотные иконки визуально отличимы как "не реализовано", не как "0% прогресса".
- Клик по каждой иконке ведёт на осмысленную панель.
- Подсказка показывает разбивку база→модификаторы→итог.
- Нет использования Tailwind, стили — в `app.css`.
- `npm run build` проходит без ошибок типов.
