# Общие принципы для волны B (Пути развития)

Эти принципы включены в каждый `TASKS.md` агента этой волны. Файл здесь — для справки. Первые 10 —
те же, что и у волны A1-A10 (`../agents/PRINCIPLES.md`), не дублируем произвольно. Пункты 11-12 — новые,
специфичные для этой волны.

## 1. Сервер = единственная правда
Все мутации мира — через `server/api.mjs` → `processTurn.mjs` или intents. Zustand на клиенте — только вьюха.

## 2. Всё новое — через ModifierStack + effects.json
Никаких отдельных "систем" в обход стека. Новые каналы — новые ключи в `channelKey` (`server/modifierStack.mjs`).

## 3. Новые intents — в content/core/intents.json
С `ap` и `ops`. Новые ops — в `server/processTurn.mjs` или специализированном модуле.

## 4. Контент — в JSON-паках content/core/
Не в коде. Новые типы эффектов — в `effects.json`.

## 5. Новые состояния — расширения существующих типов
В `src/state/types.ts`. Без новых top-level таблиц.

## 6. RNG — только серверный
`server/dice.mjs` или `node:crypto`.

## 7. Tailwind НЕ добавлять
Стили — plain CSS в `src/styles/app.css`. Анимации — `motion` + `@use-gesture/react`.

## 8. Не ломать существующий пайплайн
`npm run smoke` и `npm run smoke:tick` — должны проходить после каждого агента.

## 9. Чат-End Summary Rule
В конце чата — `tmp/summary-{timestamp}.json`.

## 10. Миграции данных
Новые поля в существующих типах → обнови `server/normalizeWorld.mjs`. Старые сейвы грузятся без ошибок.

---

## 11. Категория ≠ хранилище (новое для этой волны)

`category`/`tier` (A-F, T1-10) — это **метаданные для сопоставления слотов и дашборда**, не место хранения
стока. С волны B сток/расход/торговля идут по конкретному `resourceId` (`map.solari`, не `currency.materia`).
Если твоя задача трогает `ledger.mjs`/`flowEngine.mjs` — сверься с B1, не изобретай параллельный способ
хранить сток.

## 12. Не расширять пилот без разрешения (новое для этой волны)

Пилот Ролей/Путей изначально — **только 🛡 Структурный и ⚡ Энергетический**. **Owner OVERRIDE 2026-08-16:** B2 расширен до 8 закрытых RoleScore id (пороги по-прежнему first-pass 5000). Не рестартить B1–B7. Catalog 428 tech — другой агент.
