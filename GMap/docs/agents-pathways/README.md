# GMap — Агенты для внедрения «Путей развития» (сессия 2026-08)

Эта папка содержит задачи для параллельных AI-агентов (Composer 2.5 / Grok 4.5) по реализации решений из
`../ECONOMY_TECH_REDESIGN_SPEC.md` и `../LORE_COSMOLOGY_SPEC.md`. Отдельная папка от `../agents/` (A1-A10,
волна 1) — это волна 2, с другим скоупом (экономика/ресурсы/пути), не пересекается по файлам напрямую, но
**зависит от того, что A1-A10 уже сделали** (ModifierStack, faction traits, loyalty — уже должны быть в коде).

**Оркестрация с волной C / IA:** см. `../agents-roadmap/README.md` (фазы продукта, батчи агентов,
запрет параллелить B4/B7 с C6/C3.T3.8).

## Как использовать

1. Сверь статус трека в таблице выше и в `../agents-roadmap/README.md`.
2. Открой новый чат с Composer 2.5 или Grok 4.5 только для ❌/🟡 или явного хвоста.
3. Закинь папку нужного агента (например `B1-resource-ledger/`).
4. Агент прочитает `TASKS.md` из этой папки и начнёт работу по цепочке.

## Важно: это не всё, что обсуждалось сегодня — и намеренно

Сессия затронула гораздо больше (Пути Силы в деталях, Доктрины Воплощения, полная эланская/хэлганская
космология, все 8 материальных путей сразу). **В работу взято только то, что уже достаточно специфицировано
и не требует непроверенных балансных чисел** — см. `../ECONOMY_TECH_REDESIGN_SPEC.md` §13 (порядок внедрения)
и раздел про когнитивную нагрузку/баланс в конце сессии. В частности:

- Пилот только на **2 ролях** (🛡 Структурный, ⚡ Энергетический), не все 8 сразу.
- Полный список технологий/построек по путям (§10.1) — **не** генерируется агентами целиком, только
  минимальный сигнатурный контент для пилотных 2 ролей (реальный баланс нужно сначала прогнать на малом
  масштабе).
- Доктрины Воплощения (Кибернетика/Синтетика/Мехинарии) — **не в этой волне**, зависят от того, заработает
  ли комбо-механика путей вообще.
- Глубокая космология (Эланские подрасы, Йу, Кси, Хиверы) — **не переносится в races.json массово**, только
  точечные фиксы багов, которые уже нашли (см. B8).
