## Цепочка задач

### T8.1. Баг: Мир Поллукс числится территорией Белатора с 98.4% ХэШахов

ХэШахи — раса Чужих, военный союзник Белатора, **не** часть населения его империи (подтверждено автором
проекта). В `public/campaigns/lo_golden_pax.json` система с планетой "Мир Поллукс" (население ~32.5М,
`raceComposition` почти целиком `race_heshah`) имеет `ownerFactionId: "faction_belator"` — это ошибка.

**Важно: не трогай `data/published.json` или другие рантайм-файлы кампании (живое состояние GM-сессии) —**
только исходный шаблон в `public/campaigns/`. Если правка должна каскадно попасть в живую сессию — это
решение мастера, не автоматизируй.

Найди систему/планету "Мир Поллукс" в `public/campaigns/lo_golden_pax.json`. **Не удаляй** запись и не
меняй население — сними `ownerFactionId: "faction_belator"` (замени на `null`/незанятая, или заведи
минимальную запись `faction_heshah`, если по контексту очевиднее — если неочевидно, оставь `null` и
подробно опиши развилку в summary для решения человеком). Расу `race_heshah` в `races.json`/реестре рас
кампании **не** создавай в этой задаче — не хватает данных для полноценной записи, только пометь как
известный пробел.

### T8.2. Раса `damilian` отсутствует, но требуется постройкой

`content/core/buildings.json → mega.gate.damyl` имеет `prerequisites: { race: "damilian" }`, но такой расы
физически нет в `content/core/races.json`. Добавь минимальную запись `race_damyl` (или `race_damilian` —
сверься с точным id, который ожидает `prerequisites.race` в постройке, используй тот же самый) — по образцу
существующих записей (`origin`, `traits: []` минимум, `habitability` — разумные дефолты). Не выдумывай
подробный лор — минимальная валидная запись, чтобы постройка не была вечно недостижимой.

### T8.3. Хиноварь не отражает лорную значимость

`map.cinnabar` (хиноварь) — из неё, по лору, полностью состоят Корхи (раса, происходящая от Хиверов), она же
используется Элатрис (эланская каста) для литоидогенеза (создание Карнед). Сейчас `properties: ["strong",
"malleable"]` — обычный конструкционный металл, без намёка на эту роль. Добавь свойство, отражающее
"материал для оживления/литоидогенеза" — если в проекте уже используется подходящий тег
(`matter_destroy`/`anomaly` у `map.blakula`, `psion_emit`/`psion_suppress` у `map.vaitid` — посмотри на
паттерн) заведи аналогичный, например `"lithogenesis"` или `"animate"` — выбери и обоснуй в summary.

### T8.4. Ред-санг и отсутствующий Грид

`map.red_sang` (B7) имеет `properties: []`, `yield: {}` — полностью пустой ресурс, при этом это один из
кристаллов-осколков Хиверов по лору (наравне с блюматидом/соларитом/вайтидом/блакулой/виолидом/хиноварью).
"Грид" из того же списка **отсутствует** в `map_resources.json` вообще. В этой задаче:
- Дай `map.red_sang` реальный `yield` и хотя бы 1-2 `properties`, консистентных с остальными Хиверскими
  кристаллами (F-категория, высокий тир, психонический/аномальный флейвор).
- Не добавляй "Грид" как новый ресурс без явного запроса — только зафиксируй его отсутствие в summary,
  решение о добавлении — за автором проекта (может быть намеренным пропуском, не обязательно багом).

### T8.5. raceVariants — 10 из 17 рас механически неотличимы

В `ships.json`/`units.json` `raceVariants` заполнены только для 7 рас (Белатор, Синт, Человек, Карнед,
Псионик, Рой, Войдборн). Добавь минимальные `raceVariants` (statsMult + переименование, по существующему
паттерну — см. `ship.cruiser`/`unit.garrison` как образец) для оставшихся 10: Нагаар, Лорды Праха, Хорн,
Хорн-Нарбури, Бариал, и 5 гибридов (`human_psionic`, `karned_synth`, `belator_horn`, `human_voidborn`,
`lord_dust_psionic`). Ориентируйся на трейты расы (`races.json`) для выбора множителей — например Лорды Праха
(`incorporeal`) логично получают бонус к `accuracy`/`hp`-типу уклонения, не к брутальной защите. Не обязательно
покрывать все 11 кораблей и все 9 юнитов для каждой расы сразу — минимум 3-4 самых ходовых (крейсер, фрегат,
гарнизон, штурмовая пехота), остальное можно оставить на будущее, отметь в summary что покрыто, что нет.

## DoD

- Мир Поллукс больше не числится территорией Белатора с ХэШахами (или решение задокументировано для
  человека, если неоднозначно).
- `race_damilian`/`race_damyl` существует, постройка `mega.gate.damyl` реально достижима.
- Хиноварь и Ред-санг несут свойства, отражающие их лорную роль.
- Минимум 10 недостающих рас получили хотя бы частичные `raceVariants`.
- Валидация контента (если есть скрипт вроде `npm run validate:races`) проходит.
