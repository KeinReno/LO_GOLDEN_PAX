# Штаб (HQ) — задачи

Файл: `src/viewer/PlayerHqPanels.tsx` (компонент `PlayerHqHome`), стили — `src/styles/app.css`, ищи блок `.hq-command*`.

## Контекст

Штаб недавно (в этой же ветке) переработан в «дашборд-роутер»: наверху приоритетный список «Внимание» (собирается из условий — бои, война, дефицит, налоговое давление, доступная наука, непрочитанный RP, очередь приказов, биржа), затем сводка по державе, затем блок «Комнаты» (кнопки-ссылки в остальные разделы с бейджами количества), затем свёрнутый `<details>` с разведкой/двором. Старая версия дублировала функциональность Экономики (свой редактор налогов, свой список категорий валют, встроенный `FlowPanel`) — это осознанно убрано, **не возвращай**.

Два главных блока этой новой вёрстки (`hq-command__attention`, `hq-command__deep`) были полностью без CSS (ноль правил) — уже починено (стили добавлены рядом с `.hq-command__combat`/`.hq-command__more` в `app.css`). Если увидишь похожий разъезжающийся/неоформленный блок — подозревай именно это, а не логику.
