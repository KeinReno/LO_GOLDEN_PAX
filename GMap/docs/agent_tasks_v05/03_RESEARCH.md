# Наука (Research) — задачи

Файлы: `src/viewer/ResearchPanel.tsx`, `src/viewer/research/*`, DnD-константы — `src/viewer/research/constants.ts` (`TECH_DND_MIME`, `COGNITIO_DND_MIME`).

## Контекст (по состоянию на момент написания — проверь заново)

Наука уже частично на правильном пути: выбор технологии открывает радиальный `ActionRing` (Изучить/В очередь/Ускорить/Эксперимент) — это ровно тот же паттерн, что и в Экономике/на Карте, ничего менять не нужно, это хороший, устоявшийся жест.

Но перетаскивание в Науке (если оно есть на текущий момент — `TECH_DND_MIME`/`COGNITIO_DND_MIME`) с высокой вероятностью реализовано через нативный HTML5 Drag-and-Drop (`draggable`/`onDragStart`/`e.dataTransfer`), а не через `DragCard`/`DropZone` из `01_PRINCIPLES_AND_GUARDRAILS.md`. Это ровно та же проблема, что была на Складе Экономики до миграции: нативный DnD плохо работает на тач-устройствах и не участвует в общей доске `CardBoard` (то есть карточку технологии нельзя перетащить, например, на систему на карте, хотя карточку ресурса теперь можно).
