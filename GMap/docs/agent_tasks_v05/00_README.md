# GMap 0_5 — задачи для параллельных агентов (Composer 2.5 / Grok 4.5)

Эта папка — пакет самостоятельных заданий по редизайну игрового интерфейса игрока (ветка `0_5`). Она написана для агента, который **не видел** исходное обсуждение — весь нужный контекст либо здесь, либо в коде.

## Порядок чтения

1. **Сначала `01_PRINCIPLES_AND_GUARDRAILS.md` — обязательно, без исключений.** Там единый язык жестов, механика `CardBoard`/`DragCard`, и, что важнее всего — раздел «уже дважды сломанное», описывающий конкретную регрессию, которая произошла ДВАЖДЫ в этом же проекте. Не пропускай его ради экономии времени — именно попытка его пропустить и привела к повтору бага.
2. Дальше — файл своего раздела (`02_HQ.md`, `03_RESEARCH.md`, и т.д.).
3. `08_CROSSCUTTING_FOLLOWUPS.md` — россыпь более мелких, не привязанных к одному разделу задач, если раздел закрыт и есть время.

## Важно перед началом работы

- **Ветка:** `0_5`, поднята от `0_4`. На момент написания этих файлов на этой же ветке параллельно работают другие агенты — **проверь `git status`/`git diff` перед тем как читать любой файл начисто**: то, что описано ниже как «текущее состояние», могло уже измениться.
- **Референсная реализация** уже есть в коде — раздел Экономика (`GMap/src/viewer/economy/StockpileSection.tsx`, `PoliciesSection.tsx`) уже построена по всем принципам ниже. Если сомневаешься, как что-то сделать — смотри, как это сделано там, а не изобретай заново.
- **Проверка перед сдачей задачи (обязательно для каждого файла, который трогаешь):**
  ```bash
  cd GMap
  npx tsc --noEmit          # единственная ожидаемая ошибка — src/state/movementRange.ts, она предсуществующая и не наша
  npx vite build --mode development   # должен пройти чисто (кроме двух известных warning про dynamic import — они старые)
  ```
- **Проверка на «невидимые» CSS-классы** (реальный баг, который уже случился в Штабе — см. `01_PRINCIPLES_AND_GUARDRAILS.md`): после любых правок JSX прогони по новым классам:
  ```bash
  grep -oE '[a-z][a-z0-9_-]*' <твой_файл>.tsx | sort -u | while read c; do
    grep -q "\.$c" ../src/styles/app.css || echo "MISSING CSS: $c"
  done
  ```
  (грубый рецепт, даст ложные срабатывания на не-классовых словах — смотри глазами на результат, но ноль ложноотрицательных для реально пропущенных классов).

## Формат сдачи

В каждом файле-задаче — список конкретных пунктов с чекбоксами. Не обязательно закрывать всё за один заход. Если по ходу работы находишь несоответствие тому, что написано здесь (файл выглядит иначе, чем описано) — это ожидаемо (дерево живое), сначала разберись в реальном текущем состоянии, потом действуй.
