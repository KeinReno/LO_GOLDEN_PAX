# Sonic Bible — рация и стол GMap

Владелец: взаимодействие **медитативное**, как Banner Saga. Запоминаемое без раздражения. Хром молчит. Музыку / «Звезду Воли» не трогать.

Синус, реле-тик и dry PTT — брак. Два прохода синтеза отвергнуты.

---

## 1. Референс: Banner Saga (Kpow / Theiler, 2014)

UI сидит **отдельным слоем** от мира: сообщает действие, не выдаёт себя как «бип меню».

Рецепт, не ассеты:

- материалы: **gold metal + crystal glass** (цепь, застёжка, crystal chink, поющая чаша как тембр, кость/перо). Чуть chunky, чуть pagan-magical. Не фэнтези-лазер.
- комната: старый кабинет с книгами, пергаментом и инструментами. Для Белатора это **стекло + латунь + сургуч + бумага**, не дубовая доска и не шахматы.
- EQ: не забивать низ, но вес оставить.
- пространство семьи: **лёгкий plate + короткий stereo delay** (L/R чуть разный slap). Dry close-mic click — противоположность этому.
- less is more. Тишина не дыра, а характер.

Ident стола = **золото/кристалл в маленькой комнате**, не squelch рации. Id `radio_squelch` остаётся (проводка), звук — тихий crystal/gold chink.

## 2. Почему синтез не медитативен

Мозг читает чистый синус и цифровой тик как тест слуха / будильник. Медитативность Banner Saga — **зерно живого объекта** (нерегулярный спектр, воздух, распад в комнате). Осциллятор этого не даёт. Источник: запись материи → нарезка → общий plate/delay. Не `renderStaffFoley.mjs`.

| Источник | Закон для стола |
|---|---|
| **Gaver 1986** — auditory icons | Маппинг на физику стола учится быстрее абстрактного earcon. Печать звучит как печать. |
| **Blattner / Brewster** — earcons | Семья держится на грубых отличиях (ритм, высота, тембр), не на микро-нюансах. Пять куев должны отличаться с закрытыми глазами. |
| **Microsoft UX Sound** | Звук только если его отсутствие заметят. Чем чаще играет — тем тише и короче. Не единственный канал информации. Семья = вариации одной темы. |
| **Apple (causality · harmony · utility)** | Звук синхронен с жестом; маленький жест ≠ большой звук; не добавлять «потому что можем». UI-слой тише нотификации. |
| **Calm Technology (Weiser)** | Периферия, не захват внимания. Стол живёт часами поверх Discord. |
| **Firaxis / Civ VII** | Два рычага: *Repetitive Tolerance* (насколько звук выносит повтор) и *Signal Level* (насколько он важен). Высокий signal → можно чуть сложнее. Высокий repeat → только короткий tactile foley. |
| **Banner Saga / Kpow** | Gold+crystal, лёгкий plate, UI не artifice. Запись, не осциллятор. |

Следствие: **хром молчит**. Hover, тап вкладки, скролл, открытие панели — без звука. Звук — на последствие, не на курсор. Новых id без спроса нет.

## 3. Иерархия (signal × repeat)

```
тишина ──────────────────────────────────────── звук
хром / hover / скролл / таб          никогда
навигация меню                       никогда (пока нет id)
RP-сообщение (radio_squelch)         ident only · самый частый · самый мягкий
сброс на систему (token_drop)        стекло · короткий · приятный
HoldButton (seal_stamp)              ритуал commit · один удар
смена хода (turn_advance)            ident + 1 низкий тон
новый контакт (contact_alert)        два ident · тревога штаба, не 112
```

Правило Microsoft/Civ в одну фразу: **частота ↑ → энергия ↓**. `radio_squelch` должен быть самым «вкусным» и самым тихим по характеру. `contact_alert` — единственный, кому позволено чуть поднять внимание, всё равно без сирены.

Громкость пятёрки: согласованный peak, stamp не орёт над squelch. Слайдер «Рация» уже есть.

## 4. Семья

**Ident:** тихий crystal/gold chink + общий plate. Узнаётся по комнате и материи, не по мелодии и не по PTT. Не колокол OST, не поющая чаша на 2 секунды.

**Материалы:** латунь/цепь/крышка = gold metal; стол = кристалл/стекло (тело дерева с записи стола вырезать HP); печать = бумага/книга + металл. Пространство: узкий stereo, plate, не зал, не космос.

**Два героя на куе максимум.** Дефолт — `__01`.

Live wav: нарезка записанных CC0 (BigSoundBank) + общий Banner Saga treat (`scripts/assembleStaffRecorded.mjs`). Синтез не источник.

## 5. Пять куев

Каждый: ident (общий) + хвост (разный). Референс = «как …, но …».

1. **radio_squelch** — 250–400 мс. Только ident.  
   Как тихий crystal chink в кабинете Banner Saga, но без тоста в баре: один удар стекла, сразу в plate, без шипения рации.

2. **turn_advance** — 500–800 мс. Ident + распад кристалла (один звон, не мелодия).  
   Как смена хода, которую узнаёшь из соседней комнаты, но это кольцо стекла в plate, не фанфара и не колокол OST.

3. **contact_alert** — 400–650 мс. Два chink, второй чуть выше, пауза ~180 мс.  
   Как двойной вызов штаба, но золото/стекло, не сирена.

4. **seal_stamp** — 300–550 мс. Книга/бумага + металл крышки. Один ритуал.  
   Как печать депеши в комнате с пергаментом, не тук по дубу.

5. **token_drop** — 180–400 мс. Стекло поставлено, звон глушится.  
   Как фишка на briefing glass, не монета, не wine-toast.

## 6. Если позже появится слой меню (нет id сейчас)

Только после спроса владельца. Тогда это **тише и короче**, чем squelch, та же материя:

- confirm / commit уже есть → `seal_stamp`
- place on map уже есть → `token_drop`
- open-channel / living table уже есть → `radio_squelch`
- гипотетический «натив меню»: 40–80 мс латунь/стекло, −8…−12 dB к ident, без второго героя

Не делать: клик на каждый тап, whoosh карточки, UI confirmation_00N, лазер, колокол.

## 7. Критерий брака (слушать, не «файл лежит»)

- постоянное шипение / AI-кровать / «телевизор»
- turn = contact = stamp = drop
- RP-squelch бесит к середине сессии
- дерево, лазер, мотив OST, хор, орган, пианино как тело
- куе тонет в Discord+музыке **или** орёт над ними
- новые id / переписанный плеер / тронутая музыка
