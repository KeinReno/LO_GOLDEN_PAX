- `UI_SYSTEMS_MASTER_SPEC.md` — feeds the `client-web` UI rebuild (migration step 4)
- `LORE_COSMOLOGY_SPEC.md` — feeds `server/domain/narrative`, `content/`

**Implementation handoff specs** (written for a delegated implementing agent to follow, not carried-over GMap design docs) live in `../agent-tasks/`, not here — see that folder's own README.
