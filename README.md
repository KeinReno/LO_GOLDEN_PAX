## Быстрый старт сессии

1. Загрузить `05_Промпт_ИИ/` — особенно `20_Дом_стиль_прозы_и_кино.md` и `17_…`.  
2. Подтянуть `00_Канон/08_Текущее_состояние.md` и `11_Открытые_узлы.md`.  
3. При споре фактов — сверить главу в `02_История/Главы/` или `19_Конфликты_канона`.  

**Письмо:** дом-стиль = Ремарк (температура) + Моэм (ум NPC) + кино-доли сцены; Хемингуэй не эталон. Полный эталон — `00_Канон/20_…` / `05_Промпт_ИИ/20_…`.

Игрок — **Император Луций Солар**. ИИ ведёт мир и NPC, не принимает решения за Императора.
