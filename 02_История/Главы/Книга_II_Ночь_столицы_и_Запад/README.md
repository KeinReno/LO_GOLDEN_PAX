# Книга II — как читать

Сессия 2 в исходнике существует в **двух формах**:

1. **Полный диалог** (сырой Discord/форум-лог) — хвост файла  
   `01_Источники/Сессия_1_сырой_лог.txt`  
   и глава **`I.11`** (после маркера «Ход 13»): приказы, Амальфея/Харн, диско, ритуал, раненые, вирус ОР и т.д.

2. **Структурированная сводка** —  
   `01_Источники/Сессия_2_сводка.md`  
   разбита на эпизоды `II.00`–`II.27` в этой папке (полный дубль блоков сводки + мета).

Для ИИ при продолжении сюжета:
- факты и арки → `II.*` + `00_Канон/07` + `08` + `11`;
- дословные реплики поздней фазы → `I.11` и сырой лог;
- секреты «Гостя» → `II.19` и `00_Канон/19` (Амальфея **не** отвергала Гостя).
